# 全部修复与收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task.

## Goal
按上一轮推荐路径把 dsh-selfnote 的可构造缺陷修成成品：恢复 `node --run test` 全绿，修预算账与 recall 兜底，给冻结的 C/B 各立独立计划，完成文档/快照同步、清理和本地单 commit。

## Architecture
- 纯 Node ESM 插件；测试链由 `package.json` 的 `test` 串联。
- 注入装配在 `lib/index.js::assembleInjection()`；设置页预算账在 `lib/index.js::budgetOf()`；检索入口在 `lib/index.js` 的 `memory_recall.execute()`。
- 会话索引在 `lib/index-store.js`；线性检索在 `lib/memory.js::recall()/searchRaw()`。
- 已发布的 C/B 契约在 `docs/记忆可解释性-设计契约-20261107.md` 冻结；本轮只写计划，不实现。

## Tech Stack
Node.js >= 20 / 内置 `node:test` 风格断言 / zstd 会话夹具 / Git / Markdown。

## Spec
1. P0：把 `tests/fair.mjs` 的固定日期夹具改成相对当前时刻，不改 `factHeat()`。
2. P2：手改 `profileOverride` 可完整存 240 码点，但注入层必须服从 `BUDGET.profile`/`profileMaxChars`。
3. P2：`budgetOf()` 的 env 读数必须与真注入 `segments.env.chars` 一致，包含 3 轮门牌收敛。
4. P2：`memory_recall` 索引分支异常时降级为线性 `recall()`，返回可用的 raw 命中。
5. 新增 `tests/r4-regressions.mjs`，插入 test 链，同步 README 数字与覆盖表。
6. C、B 各写一份独立实施计划；不改产品语义。
7. 更新本机 `docs/待办.md` 与唯一快照；清理临时文件；本地单 commit。

## Global Constraints
- TDD：每个生产改动先有失败测试并亲眼见红。
- `lib/index.js` 与 `tests/client-state.mjs` 保持纯 CRLF；其余本轮文件 LF。
- 不改版本、不 push/tag/Release/npm、不重启 DSH。
- `docs/待办.md` 刻意未跟踪，不带进 commit。
- 不加大 1000 字注入预算；不动 `tests/skipped.mjs` 字节基线。
- 跨进程锁 F1/F2/F3、配置优先级契约等仍需产品决策/安全验证，不在本轮硬塞。

## Review Focus
- 失败测试是否真的能抓到 4 个具体断裂。
- 预算账是否与真注入逐段闭合，`total` 是否等于各段之和且不超过 `limit`。
- recall 异常时是否保留 `query/mode/since/raw` 形状并如实标降级。
- 静态日期防回归、EOL、diff、临时文件清理与 commit 精确文件列表。
