# 分层人格（L0 / L1 / L2）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 selfnote 加一层每回合注入的常驻人格（L0 身份 + L1 行为规则 ≤320 字），L2 扩展设定按需可读，并把「纠偏证据 → 模型提案 → 人裁定」做成闭环。

**Architecture:** 人格存在 `~/.dsh/selfnote/persona.md`（三段 `##` 标题），由新建的 `lib/persona.js` 解析 / 校验 / 原子保存；`assembleInjection` 把它作为**第一段**插在边界句之前。纠偏证据另存 `corrections.jsonl`，只由人在设置页确认后才流进 L1；跨三份文件（persona.md / corrections.jsonl / persona.evidence.json）的写入靠 `persona.pending.json` 事务日志 + 幂等恢复兜住。

**Tech Stack:** Node ≥ 20.13（ESM）、`node:fs`、`node:crypto`、`node:assert/strict`；无第三方依赖。

**Spec:** `docs/分层人格-20261105.md`（771 行）。执行时**两份一起读** —— 本计划只写「怎么改」，不重复「为什么」。

## Global Constraints

- 测试总数：**208 → 272 项 / 20 个文件**（新增 `tests/persona.mjs`、`tests/corrections.mjs`）。
- **行尾不许漂**：`lib/index.js`、`tests/client-state.mjs` 是**纯 CRLF**；`lib/client.js`、`lib/store.js`、`lib/transfer.js`、`lib/atomic.js`、`README.md`、其余 `tests/*.mjs` 是**纯 LF**。每次 `edit` 后跑 `git diff --stat`，出现整文件 diff 就说明行尾被改了。
- **零新依赖**，不动 `dependencies` / `peerDependencies`。
- **插件不联网、不调模型**：不引入 `fetch` / `http` / 模型 SDK。纠偏只做本地文本筛，语义判断留给会话里的模型。
- 所有落盘走 `lib/atomic.js` 的 `writeAtomic` / `writeJsonAtomic`；禁止 `writeFileSync` 写用户数据。
- **模型无写入权**：`persona.md`、`persona.evidence.json`、`corrections.jsonl` 只能由人触发的 HTTP 路由或 capture 自动采集写；工具端只读。
- 字数一律用 `countChars()`（Unicode 码点），UI / API / 后端三处共用，不许各自 `.length`。
- 最终预算：`{ persona: 320, notes: 200, profile: 120, env: 230, facts: 90, habits: 40 }`，`TOTAL_BUDGET === 1000`。
- 启动时 `ensureRecover()` 必须在第一次 `GET /state` 之前跑完。

## Review Focus

规格没写、但最容易让第一次用的人踩到的五件事，各自在对应任务的测试里钉住：

1. **外部编辑器改 persona.md**（Windows 记事本会写 CRLF + BOM）——解析必须容错；超限走「截断 + 留痕」，不整段丢。→ Task 1 / Task 3
2. **emoji / 组合字符**（👨‍👩‍👧、`e` + 组合重音）：`.length` 与码点数不同，按 `.length` 判会误拒、按 `.length` 切会把代理对切碎。→ Task 1 / Task 2
3. **恢复流程被杀两次**：补完证据、删日志前再死一次，第二次启动不能重复消费、不能重复加 `count`。→ Task 5
4. **两处同时保存**（自述页 + 人格页）：都要写 `corrections.jsonl` 时不能互相覆盖。→ Task 5（串行队列 + 锁）
5. **纠偏原文里的引号与换行**：`quote` 含 `"` / `\n` / 制表符时不能把 JSONL 写坏，回读要一模一样。→ Task 6

### Task 1: persona.md 解析与字符计数

**Files:**
- Create: `lib/persona.js`
- Create: `tests/persona.mjs`

**Interfaces:**
- Produces:
  - `countChars(text: string): number` —— `[...text].length`，全插件唯一口径
  - `parsePersona(raw: string): { l0: string; l1: string; l2: string; sectionless: boolean }` —— `sectionless: true` 表示整篇没有 `##` 标题（整篇当 L1，doctor 要用它提示「建议分段」）

**解析规则（spec §4）：** 先 `raw.replace(/^\uFEFF/, '').replace(/\r\n?/g, '\n')`；行匹配 `/^##+\s*(L0|L1|L2)\b/i`（同时认中文：核心身份 / 行为规则 / 扩展设定），标题行丢弃；同一层出现两次 → 用 `\n` 拼接；**标题在但该层正文为空 → 视为该层不存在**；完全没标题 → 整篇进 `l1` 且 `sectionless: true`；认不出的标题行当普通正文保留（不吞内容）。

  - `markUsed(ids: string[], txId: string): { marked: number, conflict: string[] }` —— `used && consumedBy !== txId` 的进 `conflict`，不覆盖
- Produces（`lib/persona-tx.js`）:
  - `RULE_ALGO = 'nfkc-wp1'`
  - `normalizeRule(text): string` —— NFKC + 去空白 + 去中英标点 + 小写
  - `ruleFingerprint(text): string` —— `sha1(RULE_ALGO + '|' + normalizeRule(text)).slice(0, 16)`
  - `readEvidence()` / `writeEvidenceAfter(e)` —— `persona.evidence.json`：`{ v: 1, algo, rules: { [fp]: { count, firstAt, lastAt } } }`
  - `buildEvidenceAfter(base, rules: string[], now: string): object` —— 纯函数，返回**目标状态**（不是增量）
  - `runSerial<T>(job): Promise<T>` —— 进程内单飞队列
  - `withPersonaLock<T>(job): Promise<T>` —— `persona.lock` 用 `O_EXCL`；拿不到抛 `LockedError`（`code: 'locked'`）
  - `readTx() / beginTx({ txId, personaSha256, consume, evidenceAfter }) / clearTx()`
  - `sha256OfCurrentPersona(): string` —— 读 `persona.md` 原文算 sha256（文件不存在时返回 `sha256('')`）
  - `recover(): { action: 'none'|'replayed'|'rolled-back'|'quarantined', detail?: string }`
  - `commitPersona({ l0, l1, l2, consume }): { ok: true, consumed: string[] } | { ok: true, pending: true, error: string } | { ok: false, code, error }`

**事务不变式（spec §12.7.1）：** 日志存**目标状态**（`personaSha256` + `evidenceAfter` 整份快照），恢复 = 把文件写成目标状态，重放任意次结果相同；证据幂等靠 `used && consumedBy === txId` 跳过。
